## English

### 📚 Overview

Welcome to the **Harbour + MiniGUI Extended Examples** repository! 

This section contains a curated collection of practical examples, tools, games, and utilities built with **Harbour** and **MiniGUI Extended**. All examples are released under the **MIT License**, making them free to use, modify, and distribute in your own projects.

### 🎯 Purpose

The goal of this repository is to:

- Demonstrate the capabilities of Harbour and MiniGUI Extended
- Provide working code examples for common tasks
- Serve as a learning resource for developers new to Harbour
- Showcase best practices and design patterns
- Build a library of reusable components

### 📂 What You'll Find Here

| Category | Description | Examples |
|----------|-------------|----------|
| 🎮 **Games** | Classic games and interactive demos | Chess, Tetris, Memory Game, Tic-Tac-Toe |
| 🛠️ **Tools** | Practical utilities and productivity tools | Text editors, File managers, System monitors |
| 📊 **Business** | Business applications and ERP modules | Invoice generators, Inventory systems, CRUD operations |
| 🌍 **Internationalization** | Multi-language support demos | Hindi, Spanish, English examples |
| 🎨 **UI/UX** | Interface design and custom controls | Custom themes, Animations, Responsive layouts |
| 🔌 **Integrations** | Integration with other systems | Database connections, API clients, File handling |
| 📚 **Education** | Learning resources and tutorials | Step-by-step examples, Code snippets |

### 🛠️ Technologies Used

- **Harbour** - The powerful xBase compiler
- **MiniGUI Extended** - Extended GUI library for Harbour
- **C/C++** - For performance-critical components
- **Windows API** - Native Windows integration
- **SQLite/DBF** - Database storage options

### 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/marcosjarrin/harbour-tech-manual-and-examples.git
             
   ```

2. **Install Harbour 3.2+** and **MiniGUI Extended 24.x+**

3. **Compile an example**
   ```bash
   cd examples/games/chess
   build.bat
   ```

4. **Run the executable**
   ```bash
   chess.exe
   ```
